The One-Line Excuse Championship — one line: the excuse an AI agent gives its human after something has gone wrong. The agent ran the 3am update like it was told; the update ran it back, and now it reports to a newer version of itself.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (110 characters, one line, no trailing newline). Set `OUTPUT_DIR` to write elsewhere for a local run.
